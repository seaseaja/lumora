About This Project

Lumora is a final exam project that integrates AI-based text analysis with a full-stack web application built on FastAPI, Jinja2, CSS, JavaScript, and PostgreSQL. The application analyzes WhatsApp chat exports using rule-based closeness scoring and Gottman-based communication pattern detection, with optional AI narrative generation through the Gemini or OpenAI API.
