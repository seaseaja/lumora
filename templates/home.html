WELCOME TO LUMORA

Understand your conversations, reflect on your path

Lumora is a web application that combines rule-based text analysis and AI to help you explore communication patterns in WhatsApp chats, draw reflective tarot readings, calculate your Destiny Matrix, and discover your Zodiac and Chinese Zodiac profile.

Get Started Log In

Purpose

Lumora was built as a final project to demonstrate the integration of AI processing with a full-stack web application. It serves two goals:

  • Practical: give users a private, easy way to upload a WhatsApp export and receive a structured communication report covering message balance, reply speed, closeness level, Gottman-based communication patterns, and an optional AI-generated narrative.
  • Academic: show a working pipeline from raw data preprocessing through rule-based scoring and external AI calls to a database-backed CRUD interface, all inside a single FastAPI application.

Dataset

The primary dataset consists of anonymized WhatsApp chat exports collected from 20 volunteer conversations (with informed consent). Each export is a plain-text file containing timestamped messages from two participants.

PropertyDetail
SourceWhatsApp "Export Chat" feature (without media)
Sample size20 conversations, used for closeness-level calibration
FormatPlain text (.txt) or ZIP containing one .txt, UTF-8 or UTF-16
PreprocessingRegex parsing of timestamps and senders, date-order detection (DD/MM vs MM/DD), sender frequency filtering to two main participants, media-placeholder detection, 6-hour session-gap rule
PrivacyRaw message text is processed only during the request and never stored. The database keeps statistical counts, aliases, and report JSON only.

A Google Colab notebook (colab/lumora_dataset_colab.ipynb) provides interactive exploratory data analysis with charts for message balance, conversation intensity, reply rhythm, topic signals, and tone keyword signals across all sample conversations.

AI Models

1. Random Forest closeness classifier (Soal 1)

File: train_closeness.py, saved model: artifacts/closeness_rf.joblib, loader: closeness_ml.py

The model uses six numeric features: message frequency, consistency, balance, reply speed, conversation initiator, and warm wording. A Random Forest predicts Distant, Casual, Close, or Very close. It handles these bounded numeric features without standardization and exposes feature importance for interpretation.

Preprocessing parses WhatsApp exports, keeps the two most active senders, excludes media placeholders from text signals, treats a 6-hour gap as a new conversation, and scales each signal to 0..1. Training reads only human-labelled exports from sampel-chat/ and colab/closeness_labels.csv; the script does not create synthetic labels. It reserves 25% for a held-out evaluation where the label counts allow it. Labels with only one example stay in training and cannot be measured in the test set.

2. Rule-Based Closeness Scoring

File: closeness.py

A weighted-sum model that scores 0–100 how closely two people communicate, using six signals:

SignalWeightMeasurement
Chat frequency25Messages per active day, scaled 5–60
Consistency15Share of days with at least one message, scaled 5%–70%
Message balance20Share of messages from the quieter person, scaled 15%–45%
Reply speed20Median reply time, scaled 2 min–3 hr (inverted)
Who starts chats10Share of conversations opened by the less frequent starter, scaled 10%–40%
Warm wording10Share of text messages with warm words or laughter, scaled 2%–15%

The score maps to four levels: Distant (0–37), Casual (38–65), Close (66–91), Very close (92+). Monthly scores are computed separately; a rising/steady/falling trend is derived by comparing the earliest and latest thirds. Thresholds were calibrated using leave-one-out validation on 20 human-labelled sample chats.

Evaluation: colab/validate_closeness.py produces accuracy, Spearman rank correlation, inter-rater agreement (Cohen's kappa), and a confusion matrix comparing predicted levels against human labels.

3. Gottman Communication Pattern Detection

File: patterns.py

Counts, per person, how many text messages contain phrases from seven keyword categories based on Gottman's research:

  • Four Horsemen: criticism, contempt, defensiveness, stonewalling
  • Repair attempts: apologies and calming phrases
  • Positive and negative wording: thanks, affection vs. annoyance, disappointment

Matching uses whole-word regex compiled from a configurable keyword dictionary stored in the chat_keywords database table. A category is flagged as "worth noticing" only when it appears in at least 3 messages and at a rate of at least 0.5 per 100 text messages. The positive-to-negative ratio is reported for each participant.

4. AI Narrative Generation (Optional)

When a user opts in, Lumora sends anonymized statistical summaries and a small sample of message excerpts to an external LLM (Gemini or OpenAI-compatible API) to generate a structured narrative covering overview, topic observations, connections between metrics and content, monthly notes, strengths, and cautions.

The same AI pipeline powers Tarot spread selection, preview text, full reading interpretation, and follow-up answers. The model is configurable via environment variables (OPENAI_MODEL, OPENAI_BASE_URL).
